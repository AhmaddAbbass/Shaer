# GRPO

This folder contains exploratory post-SFT reinforcement-learning code built on top of the Shaer SFT baseline.

It is **not** part of the paper’s main reported method. The paper-facing repo keeps this code as follow-up research material only.

## Starting point

- trusted baseline: `Shaer-AI/Shaer-adapters`

## Main files

- [train_grpo.py](./train_grpo.py)
- [grpo_config.yaml](./grpo_config.yaml)
- [MODEL_LINEAGE.md](./MODEL_LINEAGE.md)
- [rewards/](./rewards/)
- [prompts/](./prompts/)

## Notes

- Generated GRPO run outputs are intentionally not part of the public repo history.
- If you only care about the paper’s reported system, focus on the SFT and evaluation folders instead.
